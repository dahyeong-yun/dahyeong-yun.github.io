## 들어가며

오늘날 우리는 자바나 파이썬, 자바스크립트에서 아무런 고민 없이 `let x = 3.14 * 2.5;` 같은 소수점 연산을 작성한다. 현대 CPU에는 하드웨어 FPU(부동소수점 연산 장치)가 내장되어 있어 수 나노초 만에 계산이 끝나기 때문이다.

하지만 컴퓨터 역사상 최초의 상용 개인용 컴퓨터였던 **MITS 알테어 8800(Altair 8800)**이 등장했던 1975년의 상황은 전혀 달랐다. 

전체 메모리(RAM)가 **고작 4KB**에 불과했고, 탑재된 인텔 8080 CPU에는 곱셈이나 나눗셈 명령어조차 없었다. 이 열악한 환경에서 빌 게이츠와 폴 앨런이 창업한 '마이크로소프트(당시 Micro-Soft)'의 첫 제품인 **알테어 베이직(Altair BASIC)**이 세계를 뒤흔든 비결 뒤에는, 역사 속에서 종종 가려진 세 번째 인물 **몬테 다비도프(Monte Davidoff)**가 있었다.

---

## 1. 정수(Integer)의 시대, 그리고 빌 게이츠의 도박

1970년대 중반, 취미 개발자들을 중심으로 유행하던 마이크로컴퓨터용 언어는 톰 피트먼(Tom Pittman)이나 데니스 앨리슨(Dennis Allison)이 주도한 **Tiny BASIC** 계열이었다. 

이들의 철학은 명확했다. *"4KB 메모리 안에서는 인터프리터만으로도 벅차니, 소수점은 포기하고 오직 정수(Integer)만 지원하자."*

하지만 하버드 학부생이었던 **빌 게이츠**와 **폴 앨런**의 생각은 달랐다.
> *"정수만 지원하는 장난감 컴퓨터로는 과학 계산도, 엔지니어링도, 비즈니스 스프레드시트도 만들 수 없다. 상업적으로 성공하려면 무조건 4KB 안에서 실수(부동소수점) 연산이 돌아가야 한다."*

문제는 4KB(4,096바이트)라는 극단적인 제약이었다. 인터프리터 구문 분석기, 메모리 관리자, 문자열 처리기, 그리고 사용자가 작성할 베이직 프로그램 공간(~790바이트)까지 남기려면, **부동소수점 연산 패키지 전체를 1KB 안팎으로 완성**해야 했다.

빌 게이츠는 하버드 에이컨 전산실(Aiken Computation Lab) 동기이자 수치해석 알고리즘에 탁월했던 기숙사 친구 **몬테 다비도프**에게 손을 내밀었다.

## 2. 하드웨어 곱셈기 없는 8080에서 실수를 계산하는 법

몬테 다비도프가 마주한 인텔 8080 CPU는 덧셈(`ADD`), 뺄셈(`SUB`), 그리고 1비트씩 왼쪽/오른쪽으로 미는 시프트 명령어가 전부였다. 

다비도프는 IEEE 754 표준(1985년)이 만들어지기 10년 전, 다음과 같은 천재적인 구조를 고안했다.

### 4바이트 MBF (Microsoft Binary Format)의 탄생
다비도프는 4바이트(32비트)로 실수를 표현하는 독자적인 수치 포맷을 정의했다:
* **지수(Exponent, 8비트)**: $2^e$를 표현하며 128 바이어스를 적용.
* **부호(Sign, 1비트)**: 양수/음수 판별.
* **가수(Mantissa, 23비트 + 암묵적 1비트 = 24비트)**: 정규화된 2진수 표기법을 도입하여 유효숫자 6~7자리를 보장.

```text
[ 1바이트 지수 ] + [ 1바이트 부호/가수 상위 ] + [ 1바이트 가수 중위 ] + [ 1바이트 가수 하위 ]
```

### 24번의 비트 시프트와 덧셈 루프
인텔 8080에는 곱셈기가 없었기 때문에, 두 실수의 24비트 가수부를 곱하려면 종이에 손으로 긴 곱셈을 하듯 **비트를 1칸씩 밀면서 24번 더하는 루프**를 어셈블리어로 작성해야 했다.

```assembly
; Altair BASIC 3.2 소스코드 속 몬테 다비도프의 FMUL 루틴 발췌
FMUL:   CALL    FPCOMP      ; 0인지 확인 및 결과 부호 결정
        ...
        MVI     C, 24       ; C 레지스터에 24(비트 수) 저장
FMULLP: DAD     H           ; 1비트 왼쪽 시프트 (Carry 확인)
        JNC     NOADD       ; 비트가 0이면 덧셈 건너뜀
        DAD     D           ; 비트가 1이면 승수(Multiplicand)를 누적 가산
NOADD:  DCR     C           ; 카운터 감소
        JNZ     FMULLP      ; 24번 돌 때까지 반복
```

다비도프는 메모리의 특정 4바이트를 **`FAC`(Floating Point Accumulator, 가상 부동소수점 누산기)**로 지정하고, 이 위에서 덧셈(`FADD`), 뺄셈(`FSUB`), 곱셈(`FMUL`), 나눗셈(`FDIV`)뿐만 아니라 정수-실수 변환(`FLOAT`), 문자열 입출력 변환(`FIN`, `FOUT`)까지 초경량 코드로 집어넣었다.

## 3. 전설의 소스코드 주석

알테어 베이직 3.2(1975)의 공개된 어셈블리 원본 소스(`BASIC.asm`)에는 이 세 사람의 역할 분담이 명백하게 적혀 있다.

```assembly
; *****************************************************************
; *                                                               *
; *   MICRO-SOFT ALTAIR BASIC 3.2 (4K EDITION)                    *
; *   WRITTEN BY BILL GATES, PAUL ALLEN AND MONTE DAVIDOFF        *
; *                                                               *
; *   PAUL ALLEN WROTE THE NON-RUNTIME STUFF.                     *
; *   BILL GATES WROTE THE RUNTIME STUFF.                         *
; *   MONTE DAVIDOFF WROTE THE MATH PACKAGE.                      *
; *                                                               *
; *****************************************************************
```

* **폴 앨런**: 하버드 PDP-10 메인프레임에서 돌아가는 8080 시뮬레이터와 부트로더 개발.
* **빌 게이츠**: 인터프리터 런타임 및 파서 개발.
* **몬테 다비도프**: 4KB 메모리 신화를 가능하게 만든 부동소수점 수학 패키지 개발.

1975년 3월, 폴 앨런이 앨버커키의 MITS 본사로 날아가 알테어 8800 실기에서 종이 테이프를 넣고 최초로 베이직을 로드했을 때, 화면에 `MEMORY SIZE?` 프롬프트가 뜨고 `PRINT 2+2`를 입력하자 `4`가 출력되었다. 

그리고 곧이어 삼각함수와 실수 계산을 포함한 데모 프로그램이 완벽하게 실행되었을 때, MITS 창업자 에드 로버츠(Ed Roberts)는 경탄을 금치 못했다.

## 4. 1KB의 수학 코드가 남긴 유산

몬테 다비도프가 1975년 여름에 작성한 이 부동소수점 코어는 알테어 8800 하나로 끝나지 않았다.

1. **마이크로소프트의 모든 베이직으로 이식**:
   이후 모스 테크놀로지의 6502 CPU가 등장했을 때, 릭 와일랜드(Ric Weiland)와 다비도프는 이 수학 패키지를 6502 어셈블리로 포팅했다.
2. **PC 혁명의 표준 엔진**:
   스티브 잡스와 스티브 워즈니악의 **애플 II(Apple II)**에 탑재된 `Applesoft BASIC`, **코모도어 64(Commodore 64)**의 `Commodore BASIC`, 훗날 IBM PC의 **MS-DOS GW-BASIC**과 **QuickBASIC**에 들어간 실수 연산 엔진이 모두 다비도프의 수학 패키지에서 출발했다.

## 맺으며

오늘날 기가바이트(GB) 단위의 램과 테라플롭스(TFLOPS)급 GPU를 다루는 우리에게 **"4KB 안에 들어가는 부동소수점 엔진"**은 아득한 옛날이야기처럼 들릴 수 있다.

하지만 제약이 가장 극심했던 시절, 수학적 직관과 극한의 비트 최적화로 불가능을 가능하게 만들었던 몬테 다비도프의 코드는 오늘날 우리가 누리는 소프트웨어 생태계의 가장 밑바닥을 지탱한 초석이었다.
