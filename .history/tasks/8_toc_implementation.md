# #8 자동 목차(TOC) 기능 실제 구현 및 레이아웃 적용

이 문서는 사용자가 글을 쓸 때 수동으로 개입할 필요 없이, 테마 엔진 차원에서 자동으로 포스트 본문 내 헤딩 태그를 수집하여 반응형 규격으로 렌더링하고 스크롤 액티브 트래킹을 제공하는 자동 목차(TOC) 기능의 구현 작업 계획과 실행 내역입니다.

---

## 1. 계획 (Plan)
1. **목차 컴포넌트 신규 작성**:
   * `theme-astro/src/theme/components/TableOfContents.astro`를 새로 작성합니다.
   * `headings` 데이터를 받아 `depth` 2, 3인 헤딩들을 추출하고, 들여쓰기 뎁스를 스타일링 처리합니다.
2. **레이아웃 수정 및 스키마 연동**:
   * `theme-astro/src/theme/layouts/BlogPost.astro` 레이아웃을 수정하여 본문 영역의 우측에 Sticky 사이드바로 배치합니다.
   * 동시에 태블릿/모바일(1120px 이하)에서는 우측 사이드바가 숨겨지고, 본문 상단에 접이식 아코디언 형태의 박스로 목차를 렌더링하도록 2가지 UI 레이아웃을 하나의 소스 내에 반응형 미디어 쿼리(CSS)로 구성합니다.
3. **스크롤 하이라이팅 스크립트 연동**:
   * 컴포넌트 내 클라이언트 사이드 스크립트(`<script>`)를 사용하여 `Intersection Observer API`를 셋업합니다.
   * 화면 스크롤 시 현재 뷰포트 내에 진입한 헤딩의 목차 링크에 `.active` 클래스를 추가하여 하이라이트 스타일을 보여줍니다.
4. **로컬 교차 빌드 및 정상 동작 검증**:
   * 본체 저장소에서 로컬 테마 모듈을 연결하여 개발 서버에서 수식 페이지 및 일반 페이지의 TOC가 동적으로 잘 만들어지는지, 사이즈별로 다르게 레이아웃이 적용되는지 검증합니다.
5. **원격 릴리즈 및 락 파일 동기화**:
   * `theme-astro` 소스 코드를 푸시하고, 본체 의존성을 원격으로 돌려 락 파일을 동기화한 후 메인 커밋에 태스크 문서와 함께 푸시합니다.

---

## 2. 실행 (Execution)
1. **목차 컴포넌트 구현 완료**:
   * `theme-astro/src/theme/components/TableOfContents.astro`를 신규 생성하여 `h2`, `h3` 헤딩들을 파싱하도록 마크업을 개발했습니다.
2. **반응형 레이아웃 및 2컬럼 구현**:
   * `theme-astro/src/theme/layouts/BlogPost.astro` 레이아웃 구조를 Flex 기반의 2컬럼으로 재조정하여 데스크톱(화면 가로 > 1120px) 환경에서 우측 Sticky 사이드바로 목차를 배치했습니다.
   * `@media (max-width: 1120px)` 미디어 쿼리를 사용하여, 모바일/태블릿 화면에서는 우측 사이드바를 display none 처리하고 본문 상단에 접이식 아코디언 메뉴로 전환 노출되도록 반응형 조건 설정을 구현했습니다.
3. **Intersection Observer 하이라이팅 스크립트 탑재**:
   * 목차 컴포넌트 내에 `<script>` 태그를 이용해 브라우저 뷰포트 내 헤딩들의 진입/이탈을 관찰하고, 현재 읽고 있는 섹션의 목차 링크에 `.active` 클래스를 추가해 하이라이트 처리를 지원했습니다. Astro의 `View Transitions`로 인한 페이지 이동 시에도 오작동이 없도록 `astro:page-load` 이벤트 수신기를 셋업했습니다.
4. **로컬 교차 검증 및 원격 배포 완료**:
   * 본체 블로그에서 `npm install ../theme-astro`로 로컬 테마를 바인딩하여 수식 페이지를 포함한 포스트 상세 페이지들의 TOC 출력을 검증 완료했습니다.
   * `theme-astro` 저장소에 구현 코드를 릴리즈(`320e68b` 커밋)하고, 본체 블로그의 패키지 잠금 파일(`package-lock.json`)을 원격 링크로 최종 동기화 셋업했습니다.
