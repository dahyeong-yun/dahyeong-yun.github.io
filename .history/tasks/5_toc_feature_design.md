# #5 자동 목차(TOC) 생성 기능 설계

이 문서는 본문 내 헤딩 태그를 자동 파싱하여 독자의 편의를 돕는 스크롤 대응 목차(Table of Contents)를 구축하기 위한 설계 계획과 실행 내역입니다.

---

## 1. 계획 (Plan)
1. **데이터 추출 아키텍처 설계**:
   * Astro의 마크다운/MDX 빌드 타임 헤딩 파싱 객체(`headings`)를 활용해 데이터 공급 파이프라인을 구상합니다.
2. **목차 컴포넌트 인터페이스 설계**:
   * `TableOfContents.astro` 컴포넌트의 Props 데이터 규격과 뎁스별 스타일링 및 마크업 구조를 설계합니다.
3. **화면 배치 및 반응형 레이아웃 설계**:
   * 본문 영역 크기를 유지하면서 목차를 조화롭게 얹기 위한 CSS Grid/Sticky 구조를 설계합니다.
4. **인터랙션 및 하이라이팅 설계**:
   * `Intersection Observer API`를 이용해 화면 스크롤 위치에 맞춰 현재 헤딩 링크를 하이라이트 활성화하는 로직을 구상합니다.

---

## 2. 실행 (Execution)
1. **기획/설계 산출물 작성**:
   * 구체적인 컴포넌트 명세와 Sticky CSS 및 Intersection Observer 로직 설계안을 담은 `toc_feature_plan.md` 문서를 작성 및 검증 완료했습니다.
2. **레이아웃 배치 방안 도출**:
   * **안 A(우측 Sticky 사이드바)**와 **안 B(본문 상단 고정 박스)**의 물리적 한계 및 장단점을 도출하여 구현 방향을 조율하도록 기틀을 마련했습니다.
3. **논의 대기**:
   * 작성 완료된 상세 스펙을 바탕으로 사용자와의 레이아웃 조율 논의 상태를 대기 상태로 설정했습니다.
