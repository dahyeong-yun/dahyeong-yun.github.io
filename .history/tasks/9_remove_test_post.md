# #9 테스트용 포스트 제거 및 실서버 배포 갱신

이 문서는 실서버 배포 작동 성공 검증을 위해 임시로 생성되어 작성되었던 테스트용 포스트 파일을 감지하여 삭제하고, 실서버 글 목록 피드에서 내려가도록 배포를 갱신하기 위한 작업 계획과 실행 내역입니다.

---

## 1. 계획 (Plan)
1. **임시 포스트 파일 확인**:
   * 본체 저장소 `dahyeong-yun.github.io` 및 백업 저장소 `polymorlog-blog` 내에서 테스트용 글(예: `hello-astro-migration.md`)이 위치한 정확한 파일 경로를 식별합니다.
2. **파일 제거**:
   * 본체와 백업 저장소 양측에서 해당 마크다운 글 파일을 물리적으로 삭제합니다.
3. **로컬 빌드 검증**:
   * `npm run build` 스크립트를 재실행하여 정적 빌드 결과 리스트(`dist/blog/index.html`)에서 임시 글 라우팅이 제외되는지 확인합니다.
4. **대시보드 업데이트 및 최종 커밋**:
   * 대시보드 상태를 `🟢 Done`으로 수정하고, 본 실행 문서와 함께 소스코드 삭제 내역을 한 번에 원격 `main` 브랜치에 푸시하여 실서버 반영을 완수합니다.

---

## 2. 실행 (Execution)
1. **임시 포스트 경로 식별**:
   * 본체 및 백업 저장소 내부에서 테스트 글이 `./content/posts/retrospective/hello-astro-migration/index.mdx` 경로에 위치하고 있음을 탐색하여 확인했습니다.
2. **테스트용 글 제거**:
   * 본체 저장소와 아카이브 저장소 모두에서 `hello-astro-migration` 디렉토리와 그 내부의 `index.mdx` 파일을 `rm -rf` 명령으로 완전히 삭제했습니다.
3. **로컬 빌드 검증**:
   * `npm run build` 스크립트를 재실행하여 정적 빌드 결과 리스트(`dist/blog/index.html` 및 `dist/rss.xml` 등)에서 해당 테스트 글의 정보와 라우팅이 누락 에러 없이 깨끗하게 제거됨을 확인했습니다.
4. **원격 배포 반영**:
   * 대시보드 상태를 `🟢 Done`으로 수정하고, 삭제된 변경 이력을 원격 `main` 브랜치에 최종 묶음 푸시하여 실서버 릴리즈에 테스트 글이 삭제되도록 조치했습니다.
